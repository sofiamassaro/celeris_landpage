# Celeris — Landpage

Landpage institucional do **Celeris**, sistema de triagem inteligente para o Judiciário brasileiro. Desenvolvido como parte do Projeto Multidisciplinar Integrador.

## Sobre o projeto

O Celeris atua na entrada dos Tribunais de Justiça: lê, classifica e organiza petições iniciais automaticamente antes que qualquer servidor precise abri-las. O nome vem do latim *celeritas* (rapidez), em referência ao **Princípio da Celeridade Processual** — direito constitucional à razoável duração do processo.

Esta landpage apresenta o produto em quatro seções:

- **Sobre** — origem do nome e proposta do sistema
- **O Problema** — acúmulo de processos, sobrecarga de leitura e erro humano
- **A Solução** — triagem automática, despachos sugeridos, classificação por assunto, destaque de urgências e painel geral
- **O Valor** — impacto prático para servidores, cidadãos e o fluxo judiciário

## Tecnologias

- HTML5 semântico
- CSS3 (variáveis, grid, flexbox, media queries)
- Font Awesome 6 (ícones)

Sem frameworks ou dependências de build — basta abrir o `index.html` no navegador.

## Como rodar localmente

```
git clone <url-do-repositório>
cd celeris_landpage
# abra index.html no navegador, ou utilize Live-Server do VSCODE;
```

celeris_landpage/
